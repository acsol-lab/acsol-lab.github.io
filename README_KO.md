# ACSoL v14 — v13에서 업데이트

## 변경 사항

1. Publications 저널 이름의 글자 크기(PC 18px, 모바일 16px)는 유지하고 이전의 청록색(`#187875`)으로 되돌렸습니다.
2. Publications `Under Review` 필터를 다른 연도 필터와 동일한 둥근 버튼 디자인으로 정리했습니다.
3. 연도 선택 버튼을 `2010~2019`, `~2009`로 바꿨습니다. 필터 범위는 각각 2010~2019년, 2000~2009년으로 이전과 같습니다.
4. Students 페이지는 박사과정/석사과정별 구분 대신 **연구팀 이름별**로 표시합니다. PC의 넓은 화면에서는 5명씩, 1020px 이하에서는 4명씩, 760px 이하에서는 2명씩, 매우 좁은 화면에서는 1명씩 배치됩니다.
5. 학생 이름 옆에 학위과정 배지(석박통합과정/박사과정/석사과정)를 추가했고 기수 표시를 15px로 키웠습니다.

## Pages CMS에서 학생 입력

`01 · 콘텐츠 관리 → People · 구성원 → 재학생 · 팀별 관리`에서 각 학생의 다음 필드를 입력합니다.

- **연구팀 이름**: `Memory Team`, `Neuromorphic Team` 등 원하는 팀명을 입력합니다. **철자와 공백까지 동일**한 팀 이름으로 입력된 학생은 같은 섹션에 묶입니다. 팀별 표시 순서는 `students.json`에 처음 나타난 순서입니다.
- **학위과정 (이름 옆 표시)**: `석박통합과정`, `박사과정`, `석사과정` 중 하나를 선택합니다.
- **학생 이름 / 기수 / 소속 학과 / 이메일 / 연구 분야 / 사진**: 기존과 동일합니다.

기존 `role: phd`, `role: master` 기록은 계속 읽으며 수정하지 않아도 각각 박사과정/석사과정 배지로 표시됩니다. 기존 학생에게 `team`이 없다면 일단 **소속 팀 미지정** 그룹에 보입니다. CMS에서 팀을 채워 넣으면 자동 이동합니다. 학위과정 표시는 이름 옆에, 기수는 이름 아래에 표시합니다.

**기존 CMS 데이터 보호:** 업데이트 전용 ZIP에는 `data/` 폴더와 `media/` 폴더가 포함되지 않습니다. 기존 학생/논문/사진 데이터를 삭제하거나 덮어쓰지 않습니다. 이미 CMS에서 작성해 둔 Students 페이지 소개 문구가 `현재 연구 중인 박사과정·석사과정 학생을 소개합니다.`인 경우에는 홈페이지가 새 소개 문구로 표시하고, CMS에서 다른 문구로 수정한 경우 그대로 유지합니다.

## GitHub 배포 순서

1. GitHub 저장소 `nawit-del.github.io`를 `Code → Download ZIP`으로 먼저 백업합니다.
2. `ACSoL_v13_to_v14_Update_Only.zip`을 압축 해제합니다.
3. 안에 있는 HTML, `site.js`, `styles.css`를 기존 저장소의 동일한 경로에 덮어씁니다.
4. `.pages.yml`을 새 파일 내용으로 교체합니다. 숨김 파일 때문에 업로드가 안 되면 GitHub의 파일 편집기에서 내용을 복사·붙여넣기 해도 됩니다.
5. `data/` 및 `media/` 폴더는 유지하세요. GitHub Pages의 Actions/배포 완료 후 `Ctrl+F5`로 홈페이지를 새로고침합니다.
6. Pages CMS도 다시 열어 학생 항목의 **팀**과 **학위과정**을 입력하고 저장해 확인합니다.
7. 기존에 CMS에서 수정한 `페이지별 문구 / Students`의 소개 텍스트를 점검합니다.

## 주의

- 테스트 미리보기에는 임의의 테스트 연구원 데이터를 사용했지만 **배포 ZIP에는 포함하지 않았습니다.**
- 넓은 PC 화면에서 5열이며, 노트북 화면이 좁을 때는 가독성을 위해 4열로 변경됩니다.
- GitHub Pages/Pages CMS 실제 저장소에 업로드하고 편집을 저장하는 단계까지는 확인하지 못했습니다. 로컬 브라우저 및 파일 테스트만 수행했습니다.
