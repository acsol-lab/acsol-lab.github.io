# ACSoL Students 학위과정 + 기수 배지 업데이트 (v16.1)

기존 학생 데이터(`data/students.json`)와 CMS 설정을 변경하지 않습니다.

## 화면 변경
- 기존: `김재경  [석박통합과정]` + 다음 줄 `8학기`
- 변경: `김재경  [석박통합과정 8학기]` (기수와 학위과정을 하나의 배지로 결합)
- CMS에서 기수를 `8기`로 고치면 `[석박통합과정 8기]`로 나타납니다.
- CMS의 `cohort`가 숫자 `8`인 경우에만 화면에서 자동으로 `8기`가 붙습니다.
- '8학기'를 '8기'로 자동 변환하지 않습니다. 기존 데이터 값은 보존합니다.

## 적용
1. GitHub 저장소에서 `site.js` 파일을 첨부된 파일로 교체하세요.
2. `students.html` 파일도 교체하세요(캐시 갱신: `site.js?v=16.1`).
3. `data/`, `media/`, `.pages.yml`, CSS는 수정하지 않습니다.
4. GitHub Pages 배포 완료 후 Students 페이지를 새로고침합니다.

## 검증
- 기존 페이지에서 학생 이름과 학위과정, 기수 모두 데이터 변경 없이 읽습니다.
- 증명/일상 사진 전환과 연구팀 분류 로직은 수정하지 않았습니다.
