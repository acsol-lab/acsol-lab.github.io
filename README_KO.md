# ACSoL v16.1 기준 업데이트 — Research 요약 사진 / 세부 대표 사진 분리

이 패치는 **v16.1** 기준입니다.

## 변경 내용
- Research 항목마다 사진을 2개로 나눠서 관리할 수 있습니다.
  - **요약 카드 사진**: Home / Research 목록 카드에서 사용
  - **세부 페이지 대표 사진**: `Explore research` 클릭 후 상세 페이지 상단에서 사용
- 기존 `image` 필드는 **공통 예비 이미지**로 남겨두었습니다. 새 칸을 비워두면 예전처럼 `image`를 사용합니다.

## 교체할 파일
- `.pages.yml`
- `site.js`

## CMS에서 사용하는 방법
Research 항목 편집 화면에서 아래처럼 입력하면 됩니다.
1. `요약 카드 사진` 업로드
2. `세부 페이지 대표 사진` 업로드
3. 필요 시 각 사진 설명도 따로 입력

둘 중 하나를 비워두면 기존 `공통 예비 이미지`를 fallback으로 사용합니다.
